# キャラクター管理帳

自作キャラクターの誕生日・設定・セリフ・立ち絵・BGMを管理する、iPhone向けの静的サイトです。

## ファイル構成
- `index.html` … ページの骨組み
- `style.css` … 見た目（色・レイアウト・書体）
- `script.js` … 動き（登録・保存・ホーム画面・切り抜き・BGM）

## GitHub Pagesで公開する手順
1. GitHubで新しいリポジトリを作る（Publicを選ぶ）。
2. このフォルダの3ファイル（`index.html`・`style.css`・`script.js`）をアップロードする。
3. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存する。
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で開けるようになる。

## データの保存先（重要）
- キャラの設定は、ブラウザの localStorage に保存されます。
- 画像とBGMは、ブラウザの IndexedDB に保存されます。
- どちらもGitHubには上がりません。リポジトリにあるのは、コードだけです。
- 保存は端末とブラウザごとです。別の端末とは同期されません。
- iPhoneのSafariは、長く開かないサイトのデータを消すことがあります。「ホーム画面に追加」して使うと消えにくくなります。

## ローカルで試す
`index.html` をブラウザで開くだけで動きます。うまく動かないときは、フォルダで `python3 -m http.server` を実行して `http://localhost:8000` を開いてください。
